# 📋 Console To-Do List Application

Простая и эффективная консольная программа на Python для управления списком задач. Все данные автоматически сохраняются в файл формата JSON.

## 🚀 Функционал
* ➕ **Добавление задач** с автоматическим присвоением статуса "в процессе".
* ✅ **Изменение статуса** задачи на "completed" по её порядковому номеру.
* ❌ **Удаление задач** из списка с динамической пересборкой файла.
* 💾 **Автосохранение** — данные не теряются после закрытия терминала благодаря работе с `tasks.json`.
* 🛡️ **Защита от ошибок** — программа не падает при вводе некорректных номеров или отсутствии файла базы данных.

## 🛠️ Инструменты
* **Язык:** Python 3.x
* **Формат данных:** JSON (встроенный модуль `json`)
